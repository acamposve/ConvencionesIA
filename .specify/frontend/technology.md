# Technology

## Stack
- React 19
- TypeScript
- Vite
- Material UI
- TanStack Query
- React Router
- Axios
- React Hook Form
- Zod
- Lucide
- Vitest
- Playwright

## Recommended implementation patterns
- Use TanStack Query for server-state loading, caching, and background polling.
- Use React Hook Form with Zod for all forms, including upload validation and filter forms.
- Use a dedicated API client module for backend integration rather than mixing HTTP calls into components.
- Use MUI theming and shared components to remain consistent with the design system.
- Use Vite proxy configuration during local development to avoid CORS issues.

## Forbidden
- Redux
- Tailwind CSS
- Bootstrap
- jQuery
