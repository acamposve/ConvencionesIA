# Design System

## Palette
- Primary: #1E3A5F
- Secondary: #2F80ED
- Accent: #00B8D9
- Success: #2E7D32
- Warning: #ED6C02
- Error: #D32F2F
- Background: #F6F8FB
- Surface: #FFFFFF

Typography: Inter
Border Radius: 8px
Icons: Lucide

## Component guidance
- Use status chips for accepted, pending, failed, rejected, and completed states.
- Use cards to present classification, summary, and embedding information.
- Use skeletons and empty states consistently for loading and non-existent results.
- Prefer concise, task-oriented labels over technical implementation terms in the UI.
- Use dialogs only for destructive or high-risk actions such as deletion or reprocessing confirmation.
