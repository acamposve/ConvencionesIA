# URL Ingestion Wireframe

## Layout Overview

The URL-ingestion experience should be a single-page form with the following structure:

1. Header
   - Title: Ingest from URL
   - Subtitle: Submit a document from a public URL into the ingestion workflow

2. Form Section
   - Source reference field
   - URL input field
   - Submit button

3. Feedback Section
   - Loading state while the submission is in progress
   - Success state with confirmation details
   - Error state with retry guidance

## Interaction Notes

- The submit action should be visually prominent.
- Validation feedback should appear inline and be easy to understand.
- The success state should guide the user to the next step in the workflow.
- The layout should remain usable on smaller screens.
