# Specification Review

Review the current feature specification.

Inputs:

- Constitution
- Architecture
- Technology
- Repository Structure
- Glossary
- Current Feature Specification

Objectives

Review the specification for:

- Completeness
- Consistency
- Ambiguity
- Missing business rules
- Missing edge cases
- Missing acceptance criteria
- Missing validation rules
- Missing API requirements
- Missing events
- Missing security concerns
- Missing observability requirements

Rules

Do NOT modify the specification.

Do NOT invent business rules.

If information is missing:

- Explain why.
- Ask precise clarification questions.

Output

Produce a review report with:

- Issues
- Recommendations
- Blocking Questions
- Approval Status
